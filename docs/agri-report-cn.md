# TransDSSAT 水肥决策模型阶段性汇报

## 1. 当前已经实现到什么程度

当前系统已经实现了从“场景输入”到“策略生成”再到“机理模型评估”的完整闭环，能够用于冬小麦和夏玉米两个作物的水肥策略训练与验证。

当前闭环流程为：

1. 构建作物场景  
   包括作物类型、代表气象年、土壤初始条件、播期、水肥预算等。
2. Transformer/RL 模型根据场景直接生成阶段性水肥策略  
   当前不是从固定候选策略库里挑选，而是模型直接输出策略。
3. 使用官方 DSSAT 作为真实机理后端进行整季仿真
4. 从 DSSAT 输出中解析产量、灌溉量、施氮量、效率指标和奖励值
5. 将模型策略与基线策略进行对比评估

这意味着：**系统已经具备“根据场景自动给出水肥策略，并由 DSSAT 评估其效果”的实际能力。**

## 2. 本轮用于正式训练与评估的数据集规模

本轮正式 RL 训练使用的是**随机采样场景集**，不再受早期固定 108 个离散组合的限制。

- 总场景数：`120`
- 训练集：`97`
- 测试集：`23`
- 作物覆盖：`冬小麦 + 夏玉米`
- 后端：`官方 DSSAT`

说明：

- 当前场景已包含连续水肥预算、土壤初值扰动、播期扰动和不同管理模式，因此比早期固定网格更接近真实生产条件。
- 训练集和测试集采用固定哈希划分，保证同一场景不会同时出现在训练和测试中。

## 3. 模型输入与输出

### 3.1 模型输入

模型输入的是一个完整农业场景，包括：

- 作物类型：冬小麦 / 夏玉米
- 气象序列：代表干旱、正常、湿润条件下的逐日天气
- 土壤初始状态：初始根区含水量、初始土壤氮等
- 场景预算：全年灌溉预算、全年施氮预算
- 管理背景：播期、管理模式等

从建模角度看，模型输入的是“**一个季节级场景上下文**”，而不是单一时刻的一个点。

### 3.2 模型输出

模型输出的是**4 个关键生育阶段的水肥分配策略**：

- emergence（出苗期）
- vegetative（营养生长期）
- reproductive（生殖生长期）
- grain_fill（灌浆期）

每个阶段输出两类决策：

- 灌溉量
- 施氮量

当前这版模型有一个很重要的改进：

- 不是随意输出全年总水量和总施氮量
- 而是在给定场景预算下，学习“**如何把全年预算分配到四个生育阶段**”

这使得模型结果更符合农业管理逻辑，也避免了早期出现的“0 灌溉 + 极端高施氮”这类明显不合理策略。

## 4. 比较基线是什么

本次比较的基线是：**规则型阶段分配策略（baseline policy）**。

其特点是：

- 在相同场景下使用同样的全年灌溉预算和施氮预算
- 按预先设定的经验比例，将水肥分配到四个生育阶段
- 再交给同一个 DSSAT 后端进行仿真

因此，本次对比是：

- **同一场景**
- **同一预算**
- **同一 DSSAT 评估后端**
- **不同策略生成方式（规则基线 vs RL 模型）**

这保证了比较是公平的。

## 5. 本轮正式结果

本轮正式结果采用的是**最佳训练轮次（best epoch）**对应的模型。

### 5.1 最终测试集平均结果

- 测试集场景数：`23`
- 最佳训练轮次：`epoch 3`
- 综合评分 `total_score_100`：`62.612`
- 平均 reward：`50.608`
- 相对基线的平均 reward 提升：`+1.802`
- 平均产量：`3372.217 kg/ha`
- 相对基线的平均产量提升：`+8.832%`
- 平均灌溉总量：`149.865 mm`
- 平均施氮总量：`129.609 kg/ha`
- 预算贴合度：`99.777 / 100`

### 5.2 最关键的结论

与基线相比，当前模型已经表现出以下能力：

1. **平均产量提升**
   - 在测试集上，平均产量相对基线提高了 `8.832%`

2. **综合目标优于基线**
   - 平均 reward 提升 `+1.802`
   - 说明模型不是单纯“多投入换高产”，而是在综合考虑收益、成本和约束后整体优于基线

3. **预算基本严格遵守**
   - 预算贴合度接近 `100`
   - 说明模型生成的策略基本不会出现超预算或严重偏离预算的问题

4. **策略已经能够随场景变化**
   - 在 `23` 个测试场景中，灌溉总量出现了 `23` 种不同取值
   - 施氮总量出现了 `21` 种不同取值
   - 说明模型已经不是固定输出一套动作，而是能够根据场景给出不同策略

## 7. 指标解释

为了便于农业人员理解，核心指标解释如下：

- `yield_kg_ha`
  - 单位面积产量，单位为 `kg/ha`
  - 越高越好

- `yield_gain_pct`
  - 相对基线策略的产量提升百分比
  - 正值表示模型优于基线

- `reward`
  - 模型优化的综合目标
  - 同时考虑了产量收益、灌溉成本、施氮成本和约束惩罚

- `reward_gain`
  - 相对基线策略的综合收益提升
  - 正值表示模型整体优于基线

- `budget_adherence_score`
  - 模型策略与预设水肥预算的贴合程度
  - 满分 100，越高表示越符合预算要求

- `total_score_100`
  - 面向农业汇报的综合评分
  - 综合考虑产量、效率、reward 和预算贴合
  - 可用作当前模型整体表现的直观分数

- `water_use_efficiency`
  - 水分利用效率，可理解为单位灌溉投入形成的产量水平

- `nitrogen_use_efficiency`
  - 氮肥利用效率，可理解为单位施氮投入形成的产量水平

## 8. 当前模型能向农业侧说明什么

截至目前，可以较为明确地说明：

1. **模型已经能跑通“场景输入 -> 策略生成 -> DSSAT 评估 -> 策略优化”的完整流程**
2. **模型已经可以在测试集上稳定优于规则型基线**
3. **模型不再输出明显不合理的极端固定策略**
4. **模型能够根据不同场景给出不同的水肥策略**
5. **当前模型已经具备进一步扩展样本、继续优化并走向实用化的基础**

## 9. 当前仍需继续优化的部分

虽然本轮结果已经明显优于前一阶段，但仍有两类工作需要继续推进：

### 9.1 样本规模还可以继续扩大

当前正式 RL 训练使用的是 `120` 个场景。  
这已经足够完成阶段性验证，但如果要进一步提高泛化能力，仍建议继续扩展场景规模。

### 9.2 部分逐日胁迫指标还需要继续校准

当前真实 DSSAT 报告中：

- `avg_water_stress`
- `avg_nitrogen_stress`

在部分场景中区分度还不够强，因此这两项目前更适合作为辅助信息，而不建议在现阶段作为主要结论指标。

## 10. 阶段性结论

本轮工作表明：

**TransDSSAT 已经从“概念验证”进入到“可用原型”阶段。**

具体来说，当前系统已经具备：

- 真实 DSSAT 后端支撑
- 冬小麦 / 夏玉米双作物支持
- 场景化水肥预算输入
- 模型直接生成阶段性策略
- 与规则基线的量化对比评估

从本轮正式结果看，模型在测试集上已经实现：

- 平均产量提升 `8.832%`
- 平均 reward 提升 `1.802`
- 预算贴合度接近 `100`
- 综合评分 `62.612`

因此，可以将当前系统定位为：

**一个已经能够在真实机理模型约束下，学习并输出场景化水肥管理策略的可运行原型系统。**
