不是“概念验证”，而是已经形成了可运行、可评估、可扩展的农业决策研究闭环。

本阶段可直接对外表述的成果

  • 已完成冬小麦 / 夏玉米双作物机理模型适配。
  • 已完成文献基线、仅控水、仅控肥、联合控水肥的同口径比较。

阶段价值
04 / 07

当前成果的学术与应用价值

这一阶段的价值，不在于已经得到“最终最优策略”，而在于已经证明这条研究路线可以成立。

01

把经验管理变成可计算问题

把天气、土壤、作物、预算统一纳入同一决策框架，形成可重复、可比较的研究体系。

02

把“水肥方案”变成可评估策略

不再只看单一产量，而是同时考虑产量、资源利用、预算约束与综合得分。

03

为后续连续决策打基础

已经具备日粒度策略生成能力，下一步可以自然过渡到“每天根据实际情况再决策”。

阶段性成果的核心价值是：我们已经证明“机理模型 + 智能策略生成”能够在 realistic 的 official DSSAT 条件下形成闭环，并开始产生优于文献基线的结果。
局限性
05 / 07

当前仍然存在的局限与难点

局限 1：仅控水结果仍不理想

`water_only` 目前收益仍接近 0 或略为负值，说明单独依靠控水，在当前场景和奖励体系下还不足以稳定带来收益。

局限 2：日粒度训练更难

决策更细，动作空间更大，训练容易受到农艺约束、基线结构和数值稳定性的影响，需要更多数据与更强约束。

局限 3：还停留在仿真闭环

当前结果来自 official DSSAT 仿真，下一步仍需考虑农户真实执行偏差、现场反馈和更贴近生产的连续决策。

现阶段不宜过度宣称的内容

  • 还不能说“所有场景下联合控制都已完全最优”。
  • 还不能说“仅控水一定无效”，它更可能是当前场景与训练条件下表现偏弱。
  • 还不能替代田间试验，只能作为高效率筛选与推演工具。
目标与下一步
06 / 07

下一阶段希望达到的结果

目标排序

下一步重点

  • 继续扩大样本规模，提升联合控制训练稳定性。
  • 继续强化日粒度约束与奖励设计，避免异常策略。
  • 把“仿真最优”逐步推进到“可执行、可解释、可反馈”的生产决策。

核心判断

当前不是否定联合控制，而是已经初步证明： 联合控制在合理约束和足够样本下有潜力成为最优方向，下一阶段要做的是把这种优势稳定下来。
