# 真实场景 DSSAT 数据清单与样例（玉米 / 水稻）

## 1. 先说结论

这两份 PDF 很有用，但**还不够单独支撑一套可复现的真实场景 DSSAT 输入**。

它们更适合作为：

- 现场数据收集清单
- 模型校准补充清单
- 场景重建时的缺口提示

如果目标是“尽量还原真实场景，并让策略在真实场景下也能跑得稳”，还需要补上：

- 逐日天气序列和站点信息
- 完整土壤剖面
- 品种校准参数引用
- 播种或移栽、施肥、灌溉、排水、晒田等管理日志
- 产量、叶面积指数、生物量、土壤水氮等观测数据

如果博士已经提供了**校准好的 DSSAT 品种参数文件 / 模板**，那这两份 PDF 就可以作为“场景补充数据”；否则还不够。

---

## 2. 两份 PDF 分别覆盖了什么

### `最好补充参数(1).pdf`

主要补的是：

- 土壤剖面
- 灌溉 / 水层 / 排水 / 晒田管理
- 收获日与生理成熟期关系

这份更偏向**水稻真实场景重建**。

### `附加参数(1).pdf`

主要补的是：

- 品种基础资料
- 生物量与地块对应关系
- 生物量单位换算信息
- 过程观测

这份更偏向**品种校准与观测数据补齐**。

---

## 3. 目前还缺什么

### 3.1 必须补的

- 逐日天气序列
  - 日期
  - 最低气温
  - 最高气温
  - 降水量
  - 辐射
  - 参考蒸散
- 站点 / 地块标识
  - 站点编号
  - 地块编号
  - 小区编号
  - 最好再有经纬度
- 完整土壤剖面
  - 不是只有表层 pH / 有机质 / 碱解氮
- 品种校准引用
  - 品种名
  - 已校准 DSSAT 模板或参数文件编号
- 管理日志
  - 播种 / 移栽
  - 施肥
  - 灌溉
  - 排水 / 晒田
  - 断水

### 3.2 强烈建议补的

- 观测时间点
  - 每次观测的日期必须明确
- 观测单位
  - 克每平方米、千克每公顷、立方厘米每立方厘米这类必须统一
- 生理成熟期
  - 如果只有收获期，要说明“收获比成熟晚几天”
- 田间过程数据
  - 叶面积指数
  - 叶龄或叶片数
  - 分蘖数
  - 株高
  - 地上部生物量
  - 土壤含水量
  - 土壤硝态氮 / 铵态氮

### 3.3 仅有这些还不够

以下内容单独存在时，不足以重建真实 DSSAT 场景：

- 只有表层土壤化学指标
- 只有品种名称，没有校准参数
- 只有收获日期，没有成熟期关系
- 只有管理口头描述，没有日期和数值
- 只有产量，没有过程观测

## 4. 我们建议的最小可接受数据包

### A. 场景基础信息

必须有：

- 场景编号
- 作物名称
- 季节名称
- 地块编号
- 播种日期 或 移栽日期
- 站点名称
- 位置或经纬度
- 季长（天）

### B. 天气

必须有逐日天气表：

- 日期
- 最低气温
- 最高气温
- 降水量
- 辐射
- 参考蒸散

最好再附：

- 天气站点编号
- 数据来源
- 缺测填补规则

### C. 土壤

必须是分层剖面，不是单层摘要。

至少包含：

- 土层下边界
- 砂粒含量
- 粉粒含量
- 黏粒含量
- 容重
- 凋萎点
- 田间持水量
- 饱和含水量
- 有机碳
- 土壤 pH

### D. 品种 / 校准

至少包含：

- 品种名称
- 作物生态型
- 熟期类型
- 已校准 DSSAT 引用
- 来源

如果已经有校准好的 DSSAT 文件，则可以只给引用，不必每次重复所有参数。

### E. 管理

至少包含：

- 播种 / 移栽日期
- 行距 / 株距 / 密度
- 施肥日期、类型、用量
- 灌溉日期、方式、用量
- 对水稻额外要有排水 / 晒田 / 复水规则

### F. 观测

至少包含一种过程观测和一种结果观测：

- 过程观测
  - 叶面积指数
  - 株高
  - 生物量
  - 土壤水分
  - 土壤氮素
- 结果观测
  - 产量
  - 生理成熟期
  - 收获日期

## 6. 对水稻和玉米的差异要求

### 水稻

要额外关注：

- 移栽信息
- 田面水层
- 排水 / 晒田 / 复水
- 断水日期
- 收获日期与生理成熟期关系

### 玉米

要额外关注：

- 播种密度
- 行距 / 株距
- 施肥拆分
- 灌溉方式
- 物候观测

## 8. 结论

这两份 PDF **够用来做“补充参数清单”**，但**不够直接当作“完整真实场景输入规范”**。

如果我们要让策略在真实场景里也尽量稳，建议把它们补成一个完整的数据包，最少要覆盖：

- 天气
- 土壤剖面
- 品种 / 校准引用
- 管理日志
- 过程观测
- 结果观测

这样后续不管是做 proxy、official DSSAT，还是再往连续决策走，数据入口都会更稳。
