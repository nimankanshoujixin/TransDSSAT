# 农业合理性复核样本：正式 step-wise PPO 单场景输出

## 用途

这份材料用于请农业同学快速判断：当前正式 `step-wise PPO` 模型在一个代表性玉米测试场景上的操作时机、单次水肥量、总量与稀疏性，是否具有基本农艺合理性。

注意边界：

- 这是当前正式 `proxy + step-wise PPO` 路径的单场景 greedy 输出，不是官方 DSSAT 实测结果。
- 对照项 `heuristic baseline` 只是当前内部参考策略，不应当被当作农艺真值。

原始结构化数据见：

  [TransDSSAT 农艺复核样本：玉米单场景输入与模型输出](https://my.feishu.cn/docx/RyANdWrApo7ggFx9epCctzG1nWh)

## 为什么选这个样本

选择场景：

- `scenario_id`: `dssat_proxy-maize-rand02433-wy2016-normal-irr146-n159-balanced-profit-quzhou_fertile_silt-sw152-sn110-pd+6`

选择理由：

- 来自正式 `10000` 场景池的 `test` split
- 作物是玉米，品种是 `Denghai605`
- 天气类型是 `normal`
- 目标是 `profit`
- 管理模式是 `balanced`
- 灌溉/施氮预算接近该 test 玉米子集的中位水平，适合做“典型样本”而不是极端样本

heuristic baseline 的非零操作共 `22` 次，其中包含较多小剂量、碎片化的联合水肥操作。

| 总氮淋失 kg/ha | 41.140917 | 38.663726 |

从当前内部评分看：

- 相对 heuristic 的 `reward_gain` 为 `+2.82627`
- `budget_adherence_score` 为 `100.0`
- `total_score_100` 为 `50.968`

直观看，这个模型在该样本上实现了：

- 几乎相同的产量
- 更少的操作次数
- 更高的内部 reward

但同时也表现出：

- 施氮总量明显高于 heuristic
- 氮肥利用效率更低
- 排水和氮淋失略高

## 建议农业同学重点看什么

建议重点判断以下几点是否农艺上说得通：

1. 前 10 天已有较连续降雨的情况下，`day 5` 和 `day 10` 各浇 `30 mm` 是否合理。
2. 营养生长期的两次 `30 mm` 灌溉连在 `day 30` 和 `day 35`，以及 `day 55` 再来一次 `20 mm`，这种节奏是否像真实田间管理。
3. 施氮集中在 `day 60 / 70 / 80` 各 `40 kg/ha`，这种单次量和时间点是否合理。
4. 在这个土壤初始氮已经不低的场景里，总施氮 `120 kg/ha` 是否偏高。
5. 模型在 reproductive 阶段没有继续灌溉，只在 `day 80` 施一次氮，这样的组合是否会有明显农艺风险。

## 当前我的初步判断

如果只从“操作稀疏性”看，这个输出比当前 heuristic 更接近“农民不会频繁小剂量操作”的方向。

但如果从“具体农艺动作是否自然”看，这个样本至少有两个值得重点追问的地方：

- 前期连续降雨下仍然较早、较大剂量灌溉
- 施氮偏集中且总量不低

所以这份样本很适合作为第一轮农艺 review 材料：它不是一眼明显错误，但也确实暴露出了当前模型仍可能存在的策略偏好问题。
